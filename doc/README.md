# VibeDesignLocalMCP-2 Documentation

This folder is the active documentation set for VibeDesignLocalMCP-2.

VibeDesignLocalMCP-2 is an agent-first local design workspace. The current priority is a reliable backend/MCP/document pipeline for creating, inspecting, patching, validating, saving, reopening, and exporting HTML/SVG designs with stable node identity.

- `architecture.md` - current system shape and accepted foundation.
- `roadmap.md` - active roadmap and deferred work.
- `CONVENTIONS.md` - documentation rules for this repo.
